# Blue Room Study

Private concept materials for an interactive visitor route.

## Contents

- `prototype/` — local clickable web prototype
- `concept-deck.pptx` — editable presentation
- `concept-deck.pdf` — presentation preview
- `art-direction.md` — visual direction notes

Open `prototype/index.html` directly, or serve the `prototype` folder with any local static server.

## Usage

Internal concept only. Brand materials, fonts, images, route details, and publication rights must be approved before any public release.
