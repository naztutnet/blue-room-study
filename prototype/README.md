# «Внутри кадра» — локальный прототип

Кликабельный mobile‑first прототип цифрового спутника экскурсии по Киностудии Горького.

## Как открыть

Самый простой способ — открыть `index.html` в браузере. Для корректной работы всех функций, включая сохранение афиши, лучше запустить локальный сервер из этой папки:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Что можно попробовать

- выбрать главный интерес;
- пройти шесть демонстрационных сцен;
- послушать три синтезированных звуковых варианта;
- включить слои съёмочного павильона;
- выбрать кинопрофессию и название фильма;
- собрать и скачать персональную афишу;
- сбросить прогресс кнопкой в правом верхнем углу.

## Статус материалов

Маршрут, задания и тексты — концепция. Фотографии, логотипы, палитра и web‑шрифты взяты с публичных страниц `gorkyfilm.ru` и `museum.gorkyfilm.ru` исключительно для локальной демонстрации. Перед внешней публикацией необходимо согласовать бренд‑материалы, права, точный павильон и правила съёмки.
